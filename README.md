# GitVault Suite

SvelteKit + Bun starter project with TypeScript, ESLint, Prettier, GitHub Actions for develop branch, and a pre-commit hook.

## Structure

- src/modules: application modules
- src/domains: domain entities and business rules
- src/routes: SvelteKit routes

## Scripts

- bun install
- bun run dev
- bun run check
- bun run lint
- bun run format
